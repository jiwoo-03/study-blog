# 간략 소개
웨이퍼 맵 불량 패턴을 머신러닝·딥러닝으로 인식하고 분류하는 연구들을 정리한 리뷰 논문에 대하여 소개한다. 새 모델을 제안하는 것이 아닌 지금까지 나온 방법들을 분류 해서 장단점과 앞으로의 과제를 정리한 내용이다.
> 저자 : Tongwha Kim, Kamran Behdihan 
> 저널 : Journal of Intelligent Manifacturing 

# 연구 배경
반도체 회로 공정이 10nm 아래로 미세해지면서 웨이퍼 불량이 더 자주, 더 복잡하게 생긴다. 반도체 공정에서 웨이퍼 칩마다 전기신호를 이용한 EDS테스트를 거쳐 불량을 확인 할 수 있으나 이 방식은 느리고 비싸기 때문에 자동화가 점점 필요해졌다. 또한 **이미지 분류를 통해 불량 패턴의 모양을 확인하여 어느 공정이 문제인지를 추적(근본원인분석, RCA)**하여 사후 예방이 가능하다.

| 패턴 | 관련 공정 | 원인 |
|---|---|---|
| Random | 클린룸 | 먼지·파티클 등 환경 요인 |
| Loc / Edge-Loc | 래핑·그라인딩, 연마 | 표면 불균일, 세정 불균일 |
| Center | 연마(CMP) | 화학적 기계 연마 중 표면 불균일 |
| Edge-Ring | 래핑·그라인딩, 포토 공정 | 표면 불균일, 층간 정렬 불량, 식각 문제 |
| Scratch | 조립·패키징, 연마, 클린룸 | 취급 부주의, 연마 패드 경화, 파티클 응집 |
| Donut | 래핑·그라인딩, 연마 | 표면 불균일, 장비 취급, 연마 패드 경화 |
| Near-full | – | 여러 시스템적·랜덤 불량의 응집 |

불량은 크게 두가지로 나뉜다고 볼 수 있다.
- 랜덤 불량 : 먼지 등 환경 때문에 생기고 공정과는 관계가 없어서 보통 노이즈로 제거한다.
- 시스템적 불량 : 공정 이상 때문에 생기고 특정 공간 패턴을 보여서 이걸 분류하는 게 핵심 목표 이다.

그러나 **최근 여러 패턴이 한 웨이퍼에 겹쳐서 나타나는 일이 발생하며, 이는 혼합형 불량**이라고 부르고 있다.

# 데이터와 특징 추출

## 대표적인 공개 데이터셋
- WM-811K : 실제 공정에서 나온 웨이퍼 맵 약 81만 장 대부분 라벨이 없고, 라벨이 있느 것도 대부분이 Normal이다. 혼합 불량이 있어도 가장 눈에 띄는 패턴 하나만 라벨로 달려있다.
- Mixed WM-38 : 약 3.8만 장, 혼합형 불량이 포함된 38개 Class

## 이 분야 데이터의 고질적 문제
1. **심한 클래스 불균형 이다.** 불량보다 정상이 압도적으로 많다.
2. **라벨 부족.**엔지니어가 직접 라벨을 달아야 해서 비싸고, 사람이 하다보니 오류도 생긴다.

## 특징을 얻는 두 가지 방식
- 수작업 특징 생성 : 불량 영역의 면적·둘레·이심률 같은 기하 특징, Random 변환, 영역별 불량 밀도, GLCM 등 가볍고 도메인 지식을 반영할 수 있지만, 새로운 불량 패턴은 잡지 못한다.
- 자동 특징 추출(표현 학습) : CNN이나 Outo Encoder 특징을 스스로 학습한다. 요즘 연구는 대부분이 이쪽으로 치우쳐져있다.

# 방법론 

## 전처리
노이즈를 걸러내는 단계. median filter가 많이 쓰이는데, Scratch나 Edge-Ring 처럼 가늘고 긴 패턴까지 워버리는 문제가 있다. 그래서 다음가 같은 개선 방법들이 나왔다.
- 연결 경로 필터링(CPF) : 불량 칩들이 이어진 경로를 찾는 방식
- 그래프 기반 인접 클러스터링(AC) : 현재 가장 성능이 좋다고 평가된다.
## 지도학습(라벨 사용)
- 전통 ML : SVM, 랜덤포레스트, 앙상블 등. 예를 들어 Saqlain et al. 의 소프트 보팅 앙상블은 정확도 95.87%를 냈다. 다만 수작업 특징에 의존한다는 한계가 있다.
- CNN : Nakazawa & Kulkarni는 22개 Class에서 98.2%를 기록했다. 하지만 비슷하게 생긴 Class끼리는 자주 헷갈린다.
- 혼합형 불량은 두가지로 접근한다.
    - 다중 클래스 방식 : 패턴별 이진 CNN 여러 개를 두고 결과를 합친다.
    - 다중 라벨 방식 : 시그모이드 출력으로 각 패턴이 있을 확률을 따로 예측 한다.
- 특수 모듈 : 패턴의 기하적 변형을 학습하는 변형 합성곱(DCN), 유사도를 학습하는 Siamese 네트워크, 확신이 없으면 판정을 보류하는 reject 옵션, 객체 탐지 등

## 비지도 학습(라벨 없이)
- 클러스터링 : DBSCAN, GMM, iWMM 등으로 불량 패턴끼리 묶는다. 클러스터 개수가 같은 하이퍼 파라미터에 민감하고 느린게 단점이다.
- 사전 학습 : 라벨 없는 데이터로 Outo Encoder를 먼저 학습시켜서 가중치 초기값을 잘 잡아준다.

## 준지도학습(라벨 있는 데이터 + 없는 데이터)
라벨 없는 데이터가 압도적으로 많은 이 분야의 현실에 가장 잘맞는 방식이다. Ladder 네트워크, 준지도 VAE(SVAE), SS-CDGMM 등이 있다. 라벨 데이터가 적을수록 지도학습 CNN보다 성능이 좋았다. 연구가 아직 적어서 잠재력이 크다는게 저자들의 평가이다.

## 성능 향상 전략
- 데이터 증강 : 회전·뒤집기, 또는 GAN·VAE로 소수 클래스 데이터를 생성한다.(AdaBalGAN 등) 불균형 문제를 해결하려는 목적이다.
- 점진 학습
    - 능동 학습 : 모델이 가장 헷갈려하는 샘플만 골라 사람이 라벨을 다는 방식
    - 의사 라벨링 : 모델의 예측을 라벨처럼 쓰는 방식
단, 새로 학습하면서 기존 지식을 잊어버리는 망각 문제가 있다.
- 전이 학습 : ImageNet 등에서 사전학습된 DenseNet, VGG, Faster R-CNN을 가져와 미세조정한다. 학습 시간이 짧은게 장점이다.
- 모델 최적화 : 강화학습이나 베이지안 최적화로 하이퍼 파라미터를 자동 탐색한다.

# 결론 
## 과제 
1. 데이터 확보 : WM-811K는 이미 오래돼서 최신 웨이퍼·공정 수준을 반영하지는 못한다. 실제 최신 데이터는 기업 내부에만 있다.
2. 혼합형 불량 : 대부분의 연구가 여전히 단일 불량에 집중하고 있다.
3. 계산 비용 : 모델이 무거워서 실시간으로 공정에 적용하기 어렵다.

## 앞으로 연구가 가야할 방향 
- 클래스 불균형을 더 견고하게 처리하기
- 라벨없이 특징을 학습하는 방법, 특히 대조학습(contrastive learning)같은 자기지도 학습
- 오프라인 분석에서 실시간 모니터링으로 전환
- 체계적인 하이퍼파라미터 최적화
