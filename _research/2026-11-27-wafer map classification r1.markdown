**[ 내용 요약 : 실험 방법 흐름]**

1. **적은 라벨 데이터만으로 분류 기준 설정**
    일반적인 지도학습으로 적은 라벨 데이터만을 이용하여 결함의 종류 즉 군집형, 중심형 같은 유형의 기준을 설정한다.
2. **학습된 모델이 라벨이 없는 모델에 수도 레이블을 붙인다.**
    학습된 모델은 라벨이 없는 맵마다 결함 유형을 예측합니다. 결함 유형은 즉 전문가의 판단이 아닌 모델의 임시 판단이며, 논문에서도 이 수도 레이블에 따라 성능이 좌우 될 수 있다고 하였다.
3. **비라벨 맵 보간후 대조학습 적용**
    대조학습은 같은 이미지에서 만든 두 표현은 서로 가깝게, 다른 이미지 표현은 서로 멀게 학습시키는 방식이다. 이미지 변형 과정에서 결함 패턴의 의미가 손상될 수 있다는 점을 문제로 보고, **보간(interpolation)**을 이용해 변형된 이미지를 만든다.직관적으로는 웨이퍼 맵을 통째로 크게 자르거나 회전해 결함 모양을 바꾸기보다, 원본의 결함 구조를 유지하는 방향으로 학습용 변형을 만들려는 접근이다.
4. **분류 학습 + 대조학습**
    "이맵은 어떤 결합 유형인가?" + "이 맵과 관련된 다른 표현은 비슷한가?"를 학습한다.따라서 수도 레이블이 조금 부정확하더라도, 이미지 표현을 일관되게 학습하는 대조학습 신호가 보완 역할을 하도록 설계한 것이다.

# 서론
웨이퍼 빈 맵(WBM) 결함 패턴 분류를 자동화하여 반도체 제조 공정의 효율성을 높이는 것을 목표로 한다. 수도 레이블링 기반 준 지도 학습의 수도 레이블 의존성 문제를 완화하는 것을 목표로 한다. 이미지 증강 시 의미론적 정보 손실 문제를 완화하는 것을 목표로 한다.

많은 기업들은 반도체 생산 기술을 향상시키기위해 노력하고 있으며, 이러한 노력에는 반도체 수율을 높이기 위한 공정 개선과 불량 제품의 사점 탐지 기술 개발 등이 있다. **현실에서 불량을 FAB공정 단계에서 사전에 탐지하는 것은 계측 비용, 공정 시간 증가 등 한계가 있다.** 많은 기업들은 FAB 공정이 끝나고 EDS검사를 수행하여 웨이퍼의 각 영역이 정상적인 특성을 나타내는지 확인 후 그 결과를 WBM 형태로 나타낸다. 

WBM 형태의 EDS 검사 결과는 특정한 패턴으로 나타나는데, 이를 WBM 결함 패턴이라고 한다. 이 WBM 결함 패턴은 크게 Global random defects와 Local system defects로 분류할 수 있다. 이러한 WBM 결함 패턴으로부터 역으로 어떤 공정과정에 문제가 있는지 파악해야한다.

실제 반도체 제조 공정에서는 제품 수율 향상등의 이유로 세부 공정이 변경되는 경우가 존재한다. 이러한 상황이 발생하게 되면 기존에 발생하지 않았던 결함 패턴이 발생하게 되고, 이에따라 기존 모델의 성능이 하락하게 된다. 이를 방지하기 위해서는 모델 재학습과 같은 보완과정이 반드시 필요한데, 이러한 과정을 수행하기 위해 **WBM 데이터와 해당 데이터가 어떤 결함 패턴에 해당하는가에 대한 레이블 정보가 반드시 필요하다.** 그러나, **레이블 정보가 있는 데이터를 충분히 확보하기 위해서는 레이블링 비용이 많이 필요**하기 때문에, 소량의 레이블 정보가 있는 데이터와 다량의 레이블 정보가 없는 데이터를 활용하여 모델을 학습하는 **준지도학습 기반의 방법론이 필요하다.**

WBM과 같은 이미지 데이터에는 이미지 증강(augmentation)기법을 활용하여 데이터 부족 문제를 간접적으로 해결하기도 하는데, 이러한 경우 원본 이미지의 중요한 특징인 **의미론적 정보(semantic information)을 잃는 문제가 발생**할 수 있다. 

이러한 문제를 완화하기 **위해 본 연구에서는 Mixup 증강 방법을 대조학습 단계에서 적용**하였으며, 수도 레이블링을 활용한 준 지도학습 방법론에 대조학습을 결합하여 수도 레이블의 의존성 문제또한 완화시켰다.

# 관련 연구
- 필터링 기반의 방법과 군집 분석 기반의 연구 진행
    - 각각 직접 회로의 불량 위치 및 불량 정보에 대한 특징 추출의 한계와 비선형 데이터에 대해서 군집 형성에 어려움이 있다는 문제가 존재 
- randon-based, density-based, geometry-based 방법 으로 특징 추출 후, 앙상블 기법 적용 방법 제안, CNN 기반 모델 활용
    - 레이블 정보가 있는 데이터가 충분히 존재할 때 활용가능한 방법으로, 레이블링 비용이 높은 반도체 제조 공정에서는 실제 적용이 어렵다.
- CAE(Convolution Auto Encoder)를 활용하여 WBM의 표현 방법을 사전에 학습 한 후, 미세조성(fine tuning)을 진행하여 WBM결함 패턴 분류를 하는 방법론을 제안
    - 레이블이 존재하는 데이터를 활용하지 않고 학습을 하여 소수 클래스를 잘 분류하지 못한 문제가 발생하였다. 

이 문제를 해결하기 위해 수도 레이블링 기반의 준 지도학습 방법을 사용하여 좋은 성능을 얻었으며(Yang et al. 2020) 소량의 레이블이 존재하는 데이터를 활용(Kang & Kang, 2023)하여 WBM의 Rotation invariant representation을 학습하였다. 이를 통해 레이블이 존재하는 데이터 20%만 사용하더라도 지도학습과 비슷한 성능을 얻을 수 있었다.

## 준 지도학습 
준 지도 학습은 소량의 레이블이 존재하는 데이터에는 지도학습을 적용하고 대량의 레이블이 없는 데이터는 비 지도학습을 적용하는 방법이다.

준 지도학습의 대표적인 방법은 **수도 레이블링**을 활용한 방법이 있다.
레이블이 존재하는 데이터는 지도학습을 통해 학습 후, 레이블이 없는 데이터는 학습된 모델을 활용하여 수도 레이블이 생성된다. 수도 레이블 정보가 생성된 데이터는 기존의 레이블이 있는 데이터와 같이 활용되어 모델이 다시 학습된다.

수도 레이블을 활용한 대표적인 방법론으로는 **FixMatch**가 있다. 이는 수도 레이블을 생성할 때 레이블이 없는 데이터의 신뢰도(confidence)와 일관성(consistency)를 높여 모델의 성능을 향상시킨 방법이다. 

신뢰도 식은 다음과 같다. **레이블이 없는 데이터에 약한 증강을 적용**시킨 이미지가 모델을 통과했을 때 나온 **출력값이 특정 임계값을 넘어야 수도 레이블이 생성**되고 생성된 수도 레이블과 강한 증강을 적용한 출력값을 **크로스 엔트로피**를 적용하여 레이블이 없는 데이터에 대한 신뢰도를 높인다. 

이러한 수도 레이블링 기반의 준 지도학습에서는 수도 레이블을 생성하는 방법에 따라 모델의 성능이 달라질 수 있다. 따라서 수도 레이블의 의존성 문제를 완화하기 위해 대조학습을 결합하는 것이다.

이는 약한 증강을 적용한 이미지에 대해서 수도 레이블을 생성할 때 임베딜 벡터(embedding vector)의 유사도를 반영하였으며, 메모리 뱅크에서 K개의 약한 증강을 적용한 이미지의 수도 레이블과 임베딩 벡터를 저장하여 사용하는 memory-smoothed 수도 레이블링을 사용하였다. 또한 그래프 기반의 대조학습을 사용하여 같은 객체끼리 군집을 이룰 수 있도록 수도 레이블의 유사도를 반영한 positive sample을 정의하여 수도 레이블 의존성 문제를 완하하였다.

## 자가 지도학습
자가 지도학습은 레이블이 없는 데이터를 활용하여 데이터를 표현하기 위한 함수를 학습하는 방법이다. 대표적으로 self-prediction 기반의 방법론과 대조학습 기반의 방법론이 있다. 
- Self prediction : 각 데이터 샘플 안에서 데이터 일부를 사용해 나머지를 예측하는 작업으로 데이터의 일부를 랜덤 마스킹 후 마스킹된 부분을 재건하는 방법을 많이 사용한다.
- 대조학습 : Embedding Space에서 유사한 이미지는 가깝게, 다른 이미지는 멀어지도록 임베딩 공간을 학습하는 방법 이다.

## Wide Resiual Network 
기존 CNN모델은 깊이를 증가시키는 방향으로 발전해왔지만 이는 기울기 소실, 기울기 폭발 같은 문제가 발생한다. 이문제를 해결하기 위해 residual block을 제안하였지만 ResNet은 모델 깊이가 깊어지면서 학습 시간이 오래 걸리며, residual block의 identity mapping 문제로 일부 block만 유용한 정보를 학습하는 문제가 발생한다. 따라서 residual block의 깊이를 증가시키는 방량이 아닌 너비를 증가시키는 방향으로 모델 설계하였다. identity mapping 문제의 경우 convolution 사이에 dropout을 적용하여 문제를 해결했다.

# 제안 방법론 
이 논문의 경우 Wafer Interpolation Contrastive Leaning(WaICL)모델을 제안한다. 이는 수도 레이블링 기반의 준 지도학습 모델과 대조학습을 결합 한 모델이다. 

논문에서 제안된 방법의 전체적인 흐름은 다음과 같다. 먼저 레이블이 있는 데이터를 통해 모델 학습 후 , 레이블이 없는 데이터 중 약한 증강을 적용한 이미지를 통해 수도 레이블을 생성한다. 그 후, 생성된 수도 레이블과 강한 증강을 적용한 이미지의 분포가 같아지도록 학습을 진행한다. 다음으로 레이블이 없는 데이터를 통해 보간법 기반의 대조학습을 진행. view 에서 나온 이미지를 Mixup을 활용하여 positive samples를 재정의 한다.

논문에서 사용한 loss function은 수도 레이블링을 활용한 준 지도학습 loss와 positive smaples를 재정의한 대조학습 loss를 결합하여 사용하였다. 

# 실험 
데이터는 WM-811K를 사용하였으며, 레이블이 있는 172,950개의 데이터를 활용하여 연구를 진행했다. **레이블이 된 WBM 결함 패턴은 Center, Donut, Edge-Ring, Edge Loc, Loc, Near-Full, None, Random, Scratch로 정의**했다. 

데이터 전처리의 경우 먼저 **웨이퍼의 크기가 통일**되도록 64x64로 스케일링 하고, **RGB 3채널을 사용**하도록 하여 3차원의 이미지형태로 스케일링한다. 데이터는 8:1:1의 Train, Validation, Test로 분리하여 사용했다.

실험에서는 WideResNet, FixMatch, FixMatch + 대조학습, WaICL을 사용했다. 레이블이 일부만 존재할 때 제안한 방법론을 활용하는 경우와 가장 이상적인 상황인 레이블이 100% 존재할 때를 비교하기 위해 지도학습을 수행하여 결과를 산출했다. 위에서 언급한 FixMatch, WaICL등 다른 대조군 방법론들의 준지도학습 단계에서 인코더(encoder)로 전부 WideResNet을 활용하였기 때문에, 지도학습을 수행하는 모델도 WideResNet으로 설정. FixMatch는 수도 레이블을 활용한 준지도 학습의 대표적인 모델이므로 대조군으로 설정하였다. 또한, FixMatch와 대조학습을 결합한 모델 및 WaICL은 FixMatch 모델에 대조학습을 결합한 형태로 사용되어 수도 레이블을 활용한 준 지도학습에서의 문제 해결 여부를 확인하기 위한 목적으로 선택하였다.여기서, FixMatch에 대조학습을 결합한 모델과 제안 방법론인 WaICL의 차이는 대조학습 단계에서 보간법 방법 사용 유무이다.

모델 학습에 사용한 파라미터는 optimizer는 SGD(Stochastic Gradient Descent), learning rate는 0.03, momentum은 0.9, batch size는 64, scheduler는 cosine warm up scheduler, epoch는 100, encoder는 WiderResNet, GPU는 RTX 3090 Ti 24G를 사용하여 학습을 진행하였다.

## 하이퍼 파라미터 선택 
WaICL의 하이퍼 파라미터인 증강방법, 수도 레이블의 신뢰도를 높이기 위한 임계값, 베타 분포 생성을 위한 알파 값을 선택한다.

레이블을 10%활용한 준 지도학습 모델에서 진행하였다. WaICL은 보간방법 + FixMatch 방법이기 때문에 FixMatch 모델에서 실험을 진행하였다.

### 증강 방법 선택
레이블이 없는 데이터의 일관성 유지를 위해 강한 증강 방법은 perturb(shearing, rotation, translation)로 고정 후 약한 증강에 따른 성능 비교를 진행.

실험 결과 약한 증강에서 Rotation을 적용할때 Accuracy와 F1-Score가 가장 좋은 성능을 보여 Rotation을 선택

### 수도 레이블 신뢰도 높이기 위한 임계값 선택
WaICL에서 진행. 여러 연구에서 0.7,0.8,0.9,0.95를 사용하여 동일한 값 적용후 실험 결과 0.95에서 가장 좋은 성능 보였다.

### 베타 분포를 생성하기 위한 알파값 선택
WaICL에서 진행하며, 임의로 지정한 0.3,0.4,0.5,0.6,0.7을 사용하여 진행하였다. 0.4와 0.7에서 동일한 성능을 보여, 혼동행렬을 비교한 결과 소수 클래스 성능이 알파 0.7에서 더 좋은 결과를 보였다.

# 결론
현실적인 제조 환경에서 발생하는 혼합 패턴이나 미 발견 패턴에 대한 대응에는 분명한 한계가 존재한다. 따라서 향후 연구에서는 제안된 방법론이 복잡하고 다양한 패턴에 효과적으로 대응할 수 있는지에 대한 연구가 필요하다.
