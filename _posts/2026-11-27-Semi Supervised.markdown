# 준 지도학습(Semi Supervised Learning)
소량의 **레이블이 있는 데이터**와 대량의 **레이블이 없는 데이터**를 함께 사용하여 모델을 학습시키는 방법론

1. 소량의 정답 데이터로 모델의 **기본적인 방향(지도학습)**을 잡는다.
2. 대량의 라벨 없는 데이터에서 **데이터의 구조와 패턴(비지도학습)**을 배운다.
3. 이둘을 결합하여, 적은 정답지로도 일반화 성능이 뛰어난 모델을 만든다.

# 준 지도학습이 작동하기 위한 3가지 가정(Assumptions)
준 지도학습이 성공하려면 데이터가 다음 3가지 가정을 만족해야한다.

## 평활성 가정(Smoothness Assumption)
"가까이 있는 데이터는 같은 라벨일 확률이 높다." 
입력 공간에서 두 데이터가 가깝다면, 그들의 출력도 같아야한다. 정답이 없는 데이터라도 정답 데이터 옆에 있다면 같은 정답으로 간주한다.

## 클러스터 가정(Cluster Assumption)
"같은 군집에 속한 데이터들은 같은 라벨을 가진다."
데이터들이 뭉쳐 있다면, 그 뭉치는 하나의 클래스일 가능성이 크다. 따라서 결정 경계는 데이터가 밀집한 곳이 아니라, 밀도가 낮은 곳을 지나가야한다.

## 매니폴드 가정(Manifold Assumption)
"고차원의 데이터는 저차원의 매니폴드 위에 분포한다."
겉보기엔 복잡한 고차원 데이터도 사실은 저차원의 어떤 규칙성 위에 존재하므로, 라벨 없는 데이터를 통해 구조를 파악하면 학습에 도움이 된다.

# 주요 알고리즘 및 기법

## 자기 학습(Self-Training/Pseudo-Labeling)
가장 직관적이고 널리 쓰이는 Wrapper 방식이다.
이미 있는 지도학습 모델을 고치지 않고 그대로 두고, 그 바깥에 "학습 → 예측 → 다시 학습" 절차를 둘러씌워서 준지도학습으로 만드는 방식

1. 소량의 라벨 데이터로 모델을 1차 학습한다.
2. 학습된 모델로 라벨 없는 데이터를 예측한다.
3. 예측 결과 중 확신이 높은 데이터를 골라, 가짜 라벨을 붙인다.
4. 이 데이터를 라벨 데이터에 추가하여 다시 학습한다.

장점 : 어떤 모델에도 적용 가능하며 구현이 쉽다.
단점 : 초기에 모델이 틀린 예측을 하면, 그 오류가 계속 증폭될 수 있다.

## 그래프 기반 방법(Graph-based Methods)
데이터 간의 관계를 그래프로 표현하여 라벨을 전파하는 방식

라벨 전파 : 데이터 포인트를 노드를 보고, 유사도를 간선(Edge)으로 연결한다. 정답 데이터의 라벨 정보를 연결된 이웃 노드들로 물감을 번지듯이 전파한다.

장점 : 데이터의 구조적 특징을 잘 반영한다.
단점 : 데이터가 많아지면 그래프를 그리는 계산 비용이 커진다.

## 공동 학습(Co-Training)
서로 다른 View를 가진 두 개의 모델을 학습시키는 방식이다.

웹페이지 분류를 예로 들때 모델 A는 웹페이지의 텍스트만 보고 학습하고 모델 B는 웹페이지의 이미지만 보고 학습한다. 

모델 A가 자신있게 맞힌 데이터를 모델 B에게 가르쳐주고, 반대로 모델 B가 맞힌 걸 A에게 가르쳐주며 상호 보완하는 원리이다.

## 적대적 학습(GAN활용)
생성적 적대 신경망(GAN)활용한다.

생성자는 가짜 데이터를 만들고, 판별자는 이것이 진짜인지 가짜인지, 그리고 어떤 클래스인지를 구분하도록 학습한다.
